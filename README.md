# 1.8×10³⁰分の1 — 全生物転生シミュレーター

地球で1年に生まれる約1.8×10³⁰の命（細菌・古細菌・原生生物・菌類・植物・動物・人間）の中から、**現実の出生数の比率どおり**にひとつへ生まれ変わり、その一生を生きるブラウザゲームです。
`index.html` 1ファイルだけで動き、外部のライブラリ・画像・音源・通信は使いません。スマホの縦画面向けで、PC でも遊べます。

*A browser game: be reborn as one of the ~1.8×10³⁰ lives born on Earth each year, with real-world odds, and live that life. Japanese and English (follows the browser language).*

## 遊び方

1. タイトルで「転生の範囲」（全生物・真核生物・動物・脊椎動物・哺乳類・人間）を選んで「転生する」。なかま → すみか → 種類の順にくじが回って、生まれ先が決まります（くじはタップでとばせます）。
2. 「この一生を生きる」で一生が始まります。危険が近づいたら、画面下のボタン（または画面）を**長押しして身を守る**。守っているあいだは成長が止まり、長く守りすぎると飢えます。卵や種のように、自分では動けない時期もあります。
3. 一生が終わると、その生き物の**現実の数値**（同じように生まれたもののうち何割がそこまで生き延びるか、寿命、死因の内訳、出典など）が一覧で出ます。出会った種類は図鑑に記録されます。

操作：スマホはタッチ、PC はマウスの長押しかスペースキー。「×3」で早送り、P / Esc で一時停止、M で音のオン・オフ、Enter で次へ。

## データ

確率や生存率の出典は、ゲーム内の「データ出典」（データについて）にまとめています。多くの値は「桁が合っている」レベルの推定で、研究によって数倍の幅があります。
